# 用户提示词原文

以下按时间顺序记录本项目中用户输入的文字提示。图片附件已归档在 `docs/运行功能展示`，不在本文中重复嵌入二进制内容。

## 01

```text
假设你是一名软件工程师，使用Agentic开发实现一个完整的任务管理应用：

技术选型：
前端框架：Vue 3
构建工具：Vite
样式方案：Tailwind CSS
数据存储：localStorage

UI设计及功能需求：

1. 页面为看板（三列卡片，占主体）+一个按键：深色模式切换（一键切换、记住选择）+ 一个长条任务搜索，在最上面
2. 看板视图为三列卡片，代表三种状态：待办、进行中、已完成
3. 每列中以扁的行卡片的形式显示任务，任务只显示标题和一个代表编辑的按钮
4. 拖拽可以改变任务所在状态。
5. 点开任务编辑按钮，显示标题，描述和优先级，标题必填、描述选填
6. 优先级三档：高（红）、中（黄）、低（绿）

本轮目标：确认项目骨架，整体结构以及目录结构，包括构建github仓库
```
